# TRELLIS Studio 3.10.1

Fixed the interface update banner that reappeared after reloading the page or
restarting Studio 3.10.0. The page and backend now use the same version in the
Desktop and Server editions. An older tab still shows the reload prompt when
its interface is out of date.

To update an existing Windows installation, run the 3.10.1 Setup and select
the existing installation folder. Then reopen Studio and reload any open
Studio tabs. See the [Windows Setup guide](WINDOWS_SETUP.md) for upgrade and
repair instructions.
