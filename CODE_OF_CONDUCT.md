# Code of Conduct

TRELLIS Studio welcomes people of all backgrounds and experience levels. This
code applies to participation in project issues, pull requests, reviews and
other project spaces.

Discuss ideas, code and results respectfully. Explain disagreements in
concrete terms, welcome questions and give people room to learn. Share only
material you have permission to distribute.

Harassment, threats, discriminatory insults, unwanted sexual attention and
sharing another person's private information without permission are
unacceptable in project spaces.

## Reporting and moderation

Use GitHub's reporting tools to report harmful behavior or content. If the
report menu offers reporting to repository administrators, you can use that
option. GitHub Support also accepts abuse reports. Include a link to the
relevant content and keep private details out of public issue and pull request
threads. [GitHub reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)

Maintainers may remove harmful content, lock a thread or restrict participation
using GitHub's moderation tools. They will consider the context and severity of
the behavior when deciding how to respond.
